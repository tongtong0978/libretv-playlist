# LibreTV 整合直播源

国内外频道合并去重后的 M3U / TXT 播放列表，供 IPTV 播放器（DIYP、TVBox、TiviMate、Kodi 等）使用。

央视（CCTV-1 ~ CCTV-20、央视专题频道、部分 4K）的每一条线路都经过两轮实测，全部可拉取到 HLS 分片。

## 文件

| 文件 | 说明 |
| --- | --- |
| `cctv.m3u` | **央视专用**，36 个频道 / 85 条线路，全部实测可用，可用率 100% |
| `cctv.txt` | 同上，TXT 格式 |
| `tv.m3u` | **推荐综合版**，央视用实测线路 + 其它频道同名限 3 线路，分组名纯中文 |
| `all-channels.m3u` | 全量版，包含所有线路 |
| `all-channels.m3u8` | 同上，扩展名为 .m3u8 的副本 |
| `all-channels-lite.m3u` | 精简版，同名限 3 线路 |
| `all-channels.txt` | TXT 格式（频道名,地址 + #genre# 分组） |
| `tv.txt` | TXT 精简版 |
| `test.m3u` | 仅央视 + 卫视，用于排查网络问题 |

## 关于央视可用性

公开免费 IPTV 源里的 CCTV 线路失效率很高（原表 150 条 CCTV 线路里只有约三分之一能拉到分片）。
本仓库的央视段落已用多源交叉 + 两轮 probe 重新筛选，只保留验证通过的线路，通常每个频道 2–3 条备份。
其余频道（地方台、港澳台、国际台）仍来自公开源，可用率约 48%，属于免费源的正常水平。
