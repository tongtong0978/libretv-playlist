# LibreTV 整合直播源

国内外频道合并去重后的 M3U / TXT 播放列表，供 IPTV 播放器（DIYP、TVBox、TiviMate、Kodi 等）使用。

## v4（当前推荐）

本版做了三件事：
1. **央视整段重做**：把候选线路逐条抽帧、人工看画面，剔除了播电视购物广告（"半价抢购热线 400-066-2600"）和串台（如 CCTV-7 播《狂飙》）的假源，只留画面确实是该频道的线路。
2. **国内频道全量实测**：3216 条国内线路逐条 probe，只保留能真正拉到 HLS 分片的 1049 条，并按延迟排序、同名最多留 3 条。
3. **点播源集合**：`sources.json` 是 LibreTV 的订阅文件，内含 12 个更新快、片库大的 CMS 点播源 + 3 个直播源。

| 文件 | 说明 |
| --- | --- |
| `cctv.m3u` | **央视专用**，29 个频道 / 49 条线路，逐条抽帧核验过画面 |
| `cctv.txt` | 同上，TXT 格式 |
| `all-channels-v4.m3u` | **推荐综合版**，国内实测可用 + 国际实测可用，6416 条 / 44 分组 |
| `all-channels-v4.m3u8` | 同上，扩展名 .m3u8 的副本 |
| `all-channels-lite-v4.m3u` | 精简版（同名最多 3 线路） |
| `all-channels-v4.txt` | TXT 格式（频道名,地址 + #genre# 分组） |
| `tv-v4.m3u` | 第三方播放器友好版（分组名去掉 emoji） |
| `tv-v4.txt` | 同上 TXT 版 |
| `sources.json` | LibreTV「数据源订阅」用：12 个点播源 + 3 个直播源 |
| `test.m3u` | 仅央视 + 卫视，用于排查网络问题 |
| `all-channels-full.m3u` | 未筛选全量备份 |

## 说明

免费公开源的线路会失效，本仓库的央视段与国内段都是实测筛选后的结果；国际频道经多轮探测保留可用线路。
点播源选中后如果某部片子的线路失效，换一个源再搜即可。
